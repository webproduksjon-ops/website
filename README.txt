ABC BYGG AS – FERDIG EKSPORT

Last opp ALT innholdet i denne mappen til riktig webhotellmappe hos Domene.no.
Vanlig mappe er public_html, men bruk mappen som står i kontrollpanelet for domenet ditt.

Viktig før publisering:
1. Bytt telefonnummeret i nettsiden.
2. Koble kontaktskjemaet til en ekstern skjema-/e-posttjeneste.
3. Test domenet både med http og https, og aktiver SSL hos Domene.no.
